# Propuestas para colaborar con Voicebox

Light Meimei parte de v0.5.0. Antes de proponer cambios hay que contrastarlos con la rama actual de upstream y sus instrucciones de contribución. La marca, los valores predeterminados de esta edición y el instalador específico no se deben imponer al proyecto original.

Posibles contribuciones separadas y revisables:

1. Correcciones de geometría y desplazamiento del historial, compositor y reproductor.
2. Estados claros de generación, recuperación del progreso y sincronización de reproducción.
3. Tarjetas con acciones alineadas y actualización correcta de presets.
4. Traducción al español y normalización configurable del texto.
5. Serialización opcional de tareas y carga de modelos para equipos con poca memoria.
6. Integración Linux y guía de distribución offline como alternativa de empaquetado.

No se ha enviado un pull request ni una propuesta al repositorio original. Las pruebas locales y el historial de esta edición están documentados; una contribución futura debe incluir una reproducción concreta y pruebas adaptadas a la versión actual.
